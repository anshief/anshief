## Hola, soy Angie.

Conecto la ingeniería industrial con la ciencia de datos aplicada: entender el proceso, preparar los datos y convertir el análisis en herramientas que ayuden a decidir.

## Proyecto destacado / Priorización de leads

**¿A quién debería contactar primero un equipo comercial cuando no puede atender toda su cartera?**

Mi tesis conecta BPMN, limpieza de datos, segmentación K-Means, regresión logística y Power BI para estudiar esa decisión. El portafolio incluye un recorrido guiado, ocho pantallas anonimizadas y una demostración sintética reproducible.
